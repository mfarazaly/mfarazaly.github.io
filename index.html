About me

A developer who likes small, sharp tools.

I’m a web developer from Karachi. Most of my work is WordPress and PHP: sites that load quickly, hold up on a phone, and stay easy for someone else to update.

Somewhere along the way I started building small Windows tools for myself. System Widget began as a strip showing the Task Manager numbers I kept checking mid-game. It ended up with four themes, a proper installer and a changelog longer than I planned.

I like software that explains itself, pages that load before you notice, and fixes that remove code instead of adding it.
